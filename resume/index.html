    Professional Summary

    Technical writer and editor with nearly eight years of enterprise macOS engineering experience. Writes task-based user guides, administrator documentation, knowledge base articles, and troubleshooting content for end users and IT teams. Volunteer technical editor of the Apache OpenOffice Calc, Draw, and Impress user guides and contributor to the CIS macOS Benchmarks, including macOS 26 Tahoe. Translates complex macOS administration and security procedures into clear, audience-focused content using Markdown, Git, GitHub, and DITA. Portfolio includes an end-user onboarding guide, IT knowledge base articles, an edited administrative tool, a DITA sample, and an OpenAPI-based API documentation sample.
