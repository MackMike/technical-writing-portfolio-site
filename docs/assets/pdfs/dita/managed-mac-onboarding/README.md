# DITA Sample: Managed Mac Onboarding Guide

## Summary
This project adapts an end-user macOS onboarding guide into a modular DITA documentation set. It demonstrates structured authoring by separating explanatory, procedural, reference, and troubleshooting content into distinct DITA topic types and organizing them with a DITA map. The topics are published as styled HTML5 using the DITA Open Toolkit.

## Rebuild the Output
1. Install the DITA Open Toolkit: `brew install dita-ot`
2. From the repository root, run `scripts/build-dita-onboarding.sh`

The script builds HTML5 output into `out/` and applies the custom stylesheet in `scripts/dita-style/portfolio.css`.

## What I Learned
This sample helped me practice restructuring a linear onboarding guide into modular DITA topics. It reinforced the distinction between concept, task, reference, and troubleshooting content and showed how a documentation set can be organized through a DITA map.

Building the output with the DITA Open Toolkit also taught me how strictly DITA enforces its content model. Validation errors showed me that elements must appear in a defined order within a topic, and I corrected the task and troubleshooting topics to conform. I then wrote a custom stylesheet so the published HTML matches the rest of my portfolio.

## Notes
This project was created as a foundational DITA writing sample for a technical writing portfolio. It was my first DITA project, and I adapted an existing Markdown guide so the two formats can be compared. The scope was intentionally kept focused to demonstrate core DITA concepts clearly.
